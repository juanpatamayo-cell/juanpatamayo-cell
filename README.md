## 💡 How I work
 
> The goal is simple: build bridges between design and development, and create products where what ships is what was designed.
 
- **Systems before screens** — components, tokens and documentation that keep products consistent as teams grow
- **Patterns before symptoms** — in an audit, the value isn't listing problems, it's finding what explains them
- **Prototypes before presentations** — letting people touch a solution changes the conversation
